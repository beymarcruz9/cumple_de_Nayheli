# 🌸 Celebración Especial de Cumpleaños - Nayheli (11 Años) 🎂
> **Universo Kimetsu no Yaiba (Demon Slayer)**  
> *Creado con mucho amor por su hermano Beyker para celebrar los 11 años de Nayheli (27 de Septiembre).*

---

## 🌟 Descripción del Proyecto

Esta es una aplicación web interactiva completa, visualmente impactante y optimizada para dispositivos móviles y computadoras. Está tematizada en el universo de **Demon Slayer (Kimetsu no Yaiba)** para celebrar el cumpleaños de Nayheli.

---

## ✨ Características Principales

1. 🎬 **Opening Favorito (`video.html`):** Video especial de apertura de Demon Slayer con reproductor adaptativo.
2. ⏳ **Tiempo de Vida en Tiempo Real (`tiempo_vida.html`):** Contador en vivo desglosado en **Años, Meses, Días, Horas, Minutos y Segundos** desde el 27 de Septiembre de 2015, con tarjetas 3D cambiantes de Nezuko (`nezuko1.jpg`, `nezuko2.png`, `nezuko3.png`).
3. 🎂 **Torta & Nezuko (`torta_nezuko.html`):** Torta interactiva con **11 velas** para soplar, fondo animado con `nezuko3.png`, reproductores de los videos especiales `video_nezuko1.mp4` y `video_nezuko2.mp4`, tarjetas 3D interactivas y música de fondo (`cancion_universo.mp3`).
4. ⚔️ **Escuadrón Cazadores (`escuadron.html`):** Galería con las tarjetas 3D interactiva de Tanjiro, Zenitsu e Inosuke, acompañadas por el audio oficial del opening (`video_inicio.mp4`).
5. 🌌 **Galaxia 3D del Universo Demon Slayer (`galaxia.html`):** Galaxia tridimensional interactiva construida con **Three.js**, con fotos 3D dispersas que **cambian de formato JPG a PNG al hacer clic**, constelaciones de frases y banda sonora oficial.
6. 📜 **El Gran Final (`final.html`):** Créditos estilo película de Hollywood con la música final (`cancion_final.mp3`), agradecimientos a la familia:
   - **Hermano & Creador:** Beyker
   - **Hermanos:** Yamilda, Fidel, Deyvis, Ruben
   - **Papás:** Santos & Teodora
   - **Mascotas:** 2 Gatos (*Arroz Caldito* y *Melino*)
   - **Resto de Personajes y Pilares**
   - **Cierre:** *"LA HISTORIA CONTINÚA..."*

## 🚀 Cómo Publicar en GitHub Pages

1. **Subir los archivos a tu repositorio de GitHub:**
   ```bash
   git init
   git add .
   git commit -m "🎉 Versión final de la web de cumpleaños de Nayheli (11 Años)"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```

2. **Activar GitHub Pages:**
   * Vé a tu repositorio en GitHub.
   * Entra en **Settings** > **Pages**.
   * En **Source**, selecciona la rama `main` y la carpeta `/ (root)`.
   * Guarda los cambios. ¡En pocos segundos tendrás el enlace listo para compartir! 🌐
